# Philosophy

Intent and clarity matter more than ever as LLMs produce working yet verbose, unreadable code.

- Keep code simple, stupid. If your line count is large, it's likely wrong or soon will be. (More code = mode points of failure.)
- Keep code local. If you have to jump around files, your code is bad. Make it ergonomic.
